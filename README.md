## About

DungeonRun is a console RPG / dungeon crawler game built in C++. It was originally created as a university assignment project to demonstrate console manipulation, custom state machines, and game loop architecture in standard C++ without using heavy third-party graphical libraries.

The game runs inside a standard Windows terminal, utilizing direct Windows Console API calls for custom color rendering, double-buffering ideas, screen resizing, and interactive keyboard input.

---

## Features

- **Dynamic Terminal Adaptation**: Automatically recalculates layout boundaries and centers interface panels based on current console window size.
- **Turn-based Combat & Dodge Phase**: Standard attack/skill turns combined with an action-reaction phase where incoming enemy attacks must be dodged in real time.
- **ASCII Visuals**: Hand-crafted ASCII art for enemies, bosses, titles, and combat status indicators.
- **Progression & Inventory**: Character stats (Health, Mana, Stamina), leveling system, weapon/armor equipment, and usable potions.
- **UTF-8 Alignment**: Custom visual length calculations to ensure UI borders, text boxes, and combo bars do not break on multi-byte characters.

## How to Build

### Using CMake

1. Clone or download the repository:
```bash
git clone https://github.com/imsudoer/DungeonRun.git
cd DungeonRun
```

2. Generate build files:
```bash
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
```

3. Build the executable:
```bash
cmake --build build --config Release
```

The compiled binary `DungeonRun.exe` will be located inside `build/Release/` (or `build/` depending on your generator).

### Direct MSVC Build

If you are using the Visual Studio Developer Command Prompt:
```cmd
cl.exe /EHsc /O2 /utf-8 /Fe:DungeonRun.exe src/main.cpp user32.lib
```
